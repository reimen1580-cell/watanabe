# 戦場カメラマン 渡部陽一 — Field Notes

静的HTML/CSS/JavaScriptで構成した、渡部陽一さんの活動紹介サイトです。

## 開発

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

`http://localhost:3000` で確認できます。

本文は、渡部陽一オフィシャルサイトと株式会社ボンドの公開プロフィール・取材経歴を参照して編集しています。上越妙高タウン情報の記事は本文で扱っていないため、出典一覧から外しています。サイトは非公式で、権利確認のない肖像写真・報道写真は使用していません。

トップの `assets/hero-editorial.webp` は、このプロジェクト用に生成した抽象的なエディトリアルビジュアルです。実在人物の肖像や既存の報道写真を含めず、カメラとノートをモチーフにしています。生成元は Manus image generation、用途は本サイトのヒーロー背景、管理場所は本リポジトリです。
